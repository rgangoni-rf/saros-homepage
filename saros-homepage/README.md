# Saros Homepage v3

Página estática (um único `index.html`) publicada via GitHub Pages.

## Atualizar o site
1. Edite `index.html` no VS Code.
2. Source Control (Ctrl+Shift+G) → mensagem → **Commit** → **Sync Changes**.
3. O GitHub Actions publica sozinho em ~1 min (aba **Actions** do repositório).
